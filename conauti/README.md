# CONAUTI · Prototipo

```
conauti/
├── index.html        Estructura de las 5 pantallas
├── css/styles.css    Estilos propios y animaciones
└── js/
    ├── config.js     Constantes, límites y textos
    ├── errors.js     Sistema antierrores (avisos, wrappers, almacenamiento seguro)
    ├── utils.js      Selectores seguros y saneamiento
    ├── state.js      Estado, validaciones y borrador (aquí va Firebase)
    ├── nav.js        Navegación con guardas de paso
    ├── screen1..5.js Una pantalla por archivo
    └── app.js        Arranque
```

Abrir: doble clic en `index.html`. Despliegue: arrastrar la carpeta `conauti` a Netlify.
